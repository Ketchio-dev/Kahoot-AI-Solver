What happens when you press the key

You start each request. The screenshot goes directly to your selected provider.

Kept on your device

API keys and settings stay in your browser’s local storage (chrome.storage.local), without sync or extra encryption. Screenshots and answer history are not saved.

Use an HTTPS address for a compatible server. Plain HTTP sends your key and screenshots unencrypted.

Models that report no image support are left out. Others may still reject an image request, so test your choices on a practice quiz.

Set it up once.

  1. Open AI settings

    Install the extension, click its icon, then click ··· in the top-right corner. That opens AI settings in the current store release (v1.4.0).

  2. Connect your API

    Enter a Gemini key, an OpenAI key, or both, then click Save Keys & Reload Models. For a compatible server, enter its URL including /v1 and approve Chrome’s access prompt.

    Get a Gemini key Get an OpenAI key

  3. Pick a model for each slot

    Choose models that accept image input. Open a practice quiz, make sure the question and options are visible, and press the shortcut.

Before you install

Questions or bug reports
Do I need my own API key?

Yes. Connect a Gemini, OpenAI or compatible API account. No keys or AI credits are included; your provider may charge for requests.

Why does the popup say “Youtube Ad Blocker”?

The current store release (v1.4.0) has an old cover screen. Click ··· to open AI settings; it does not block ads. The v1.4.1 update uses the Kahoot AI Solver name and a Settings button. It has been submitted for review and is not yet published.

Does it click or submit answers for me?

No. You review the suggestion, choose an answer and submit it yourself. Use assistance only where your school or quiz host allows it.

How do Normal and Stealth differ?

Normal shows a readable answer panel for 15 seconds. Stealth uses an 8-second corner indicator: a colored shape for single-choice answers or a compact text box for other formats. Both can appear in screenshots and screen sharing.

Does it work for audio or video questions?

It does not record audio or upload video. Paste a transcript, captions or your own notes into the Audio/video context field in settings, then click a solve button in the popup. The text is sent with the screenshot, is not saved, and is cleared when the popup closes. Keyboard shortcuts send only the screenshot.

Can I use every model in the list?

Not always. A listed model may still reject an image request. Try your choice on a practice quiz. For compatible-server requirements, see the setup guide.
