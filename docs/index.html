A FEW THINGS TO KNOW

문의 · 버그 제보 ↗
API 키나 AI 크레딧이 포함되어 있나요?+

아니요. 본인의 Gemini, OpenAI 또는 호환 API 계정을 연결해야 해요. API 사용 요금은 선택한 제공업체가 청구하며, 이 확장 프로그램에는 API 키나 크레딧이 포함되어 있지 않아요.

답을 자동으로 클릭하거나 제출하나요?+

아니요. 화면에 답변 제안만 표시해요. 정확성을 직접 확인하고, 사용자가 보기를 선택하고 제출해야 해요. 학습·연습·연구용으로, AI 도움을 허용하는 환경에서만 사용하세요.

Normal과 Stealth는 어떻게 다른가요?+

Normal은 읽기 쉬운 패널을 15초 동안 보여줘요. Stealth는 단일 선택 답을 작은 모서리 도형으로, 복잡한 답은 작은 텍스트 상자로 8초 동안 보여줘요. 둘 다 화면 캡처나 화면 공유에 보일 수 있어요.

오디오나 동영상 문제도 되나요?+

오디오 녹음이나 동영상 업로드는 지원하지 않아요. 설정의 Audio/video context에 자막, 대본, 관찰한 내용을 붙여 넣고 팝업의 실행 버튼을 누르면 화면 캡처와 함께 보내요. 이 문맥은 저장되지 않고 팝업을 닫으면 지워져요. 단축키는 화면 캡처만 보내요.

목록에 나오는 모든 모델을 쓸 수 있나요?+

반드시 그렇지는 않아요. 이미지 입력과 API 호환 여부는 제공업체에 따라 달라서, 목록에 있어도 요청을 거부할 수 있어요. 호환 서버는 /models와 이미지 입력을 받는 /chat/completions를 지원해야 해요. 필요한 정보가 화면에 없거나 모델이 잘못 해석하면 정확한 답을 얻을 수 없어요.
