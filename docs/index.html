Set up the extension

  1. Load the 2.0.1 build

    Download the 2.0.1 ZIP and unzip it. At chrome://extensions/, turn on Developer mode and select Load unpacked. Pick the folder containing manifest.json.

    Download 2.0.1 ZIP

  2. Connect your API key

    Open Settings, enter your provider key and select Save keys & load models. For a compatible server, use its HTTPS API base URL ending in /v1.

    Gemini key OpenAI key

  3. Pick a model and solve

    Choose an image-capable model in any slot. Show the question and choices on the active tab, then click Solve or use the displayed shortcut.

    Alt + ZAlt + XAlt + COption on Mac

Before your first solve

Settings stay in your Chrome profile. The screenshot and any optional transcript go to the provider you select when you solve.

Privacy policy
Why does the store version say “Youtube Ad Blocker”?

That cover appears in store version 1.4.0. Use the three-dot button to open its AI settings. The 2.0.1 unpacked build opens straight to Kahoot AI Solver.

What if I only see colored buttons in Kahoot?

Ask the quiz host to enable questions and answers on participant screens. The extension needs the question text and choices visible on the captured tab.

Which answer formats are supported?

Single choice, multiple choice, typed answers, ordered choices and slider values. For an audio or video question, you can include a transcript with the popup's Solve button.

Why does my model reject the screenshot?

Model lists may omit image support or API compatibility. Choose a model that accepts images and check the account’s permissions and usage limit.
