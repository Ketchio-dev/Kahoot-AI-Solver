Privacy policy ↗
Your browserScreenshot + optional context→Your chosen AIGemini · OpenAI · compatible API
Keys and settings stay local
API keys and model choices are stored in chrome.storage.local in your browser profile. That is ordinary browser storage, not extra encryption added by the extension.
The visible screen is sent when you run it
A shortcut or popup button captures the visible area of the current tab. Don’t run it while private information is on screen.
Cost and data policies come from your provider
API charges and retention rules depend on the service you connect. Use a trusted HTTPS address for compatible servers.

A FEW THINGS TO KNOW

Questions before
you install.

Questions or bug reports ↗
Does it include an API key or AI credits?+

No. You connect your own Gemini, OpenAI or compatible API account. Your provider bills you for API usage, and the extension includes no key or credits.

Does it click or submit answers for me?+

No. It only shows a suggestion on the page. You check it, pick the option and submit it yourself. Use it for learning, practice and research, and only where AI help is allowed.

How do Normal and Stealth differ?+

Normal shows a readable panel for 15 seconds. Stealth shows a small corner shape for single-choice answers, or a small text box for richer answers, for 8 seconds. Both can appear in screenshots and screen sharing.

Does it work for audio or video questions?+

It doesn’t record audio or upload video. Paste a transcript, captions or your own notes into the Audio/video context field in settings, then click a solve button in the popup. The text is sent with the screenshot, isn’t saved, and is cleared when the popup closes. Keyboard shortcuts send only the screenshot.

Can I use every model in the list?+

Not necessarily. Image-input support and API compatibility depend on the provider, so a listed model may still reject a request. A compatible server must support /models and a /chat/completions endpoint that accepts image input. If the screen doesn’t show what’s needed, or the model misreads it, you won’t get a reliable answer.
